# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the Pulso and macOS versions, the steps to reproduce and the impact you expect.

You should get a first reply within 7 days. Once a fix is released, the report is disclosed in the release notes with credit to the reporter, unless you ask to stay anonymous.

## Scope

Pulso reads system statistics locally. The only network requests it makes are the opt-in public IP lookup and the latency check, both described in Settings. Reports about data leaving the Mac without the user opting in are especially welcome.
